# Telegram Instant View

This directory contains the Instant View template for [atravkina.ru](https://atravkina.ru).

## What it does

The template targets individual blog entries under `/blog/<slug>/`. It deliberately does not target the blog index, pagination, or other site pages.

It uses the page title generated by Datenstrom Yellow, extracts the article from the `<article>` element in the `blog.html` layout, and removes the previous/next navigation links. Telegram's Instant View renderer handles supported article markup such as paragraphs, headings, links, lists, quotations, preformatted code, and images.

The template does not change the website or its HTML. It is a set of extraction rules that Telegram applies when it fetches a page.

## Install the template

1. Open [Telegram Instant View Editor](https://instantview.telegram.org/).
2. Sign in with the Telegram account that will own the template.
3. Create a template for `atravkina.ru`.
4. Copy the complete contents of [atravkina.iv](./atravkina.iv) into the editor.
5. Test several individual blog posts, including posts with images, headings, links, quotes, and code.
6. Use Track Changes on at least 10–15 different article URLs and check that the full article is preserved and interface elements are excluded.
7. When the results are correct, submit the template for Telegram review.

Telegram's review is required before Instant View is reliably offered to all Telegram users for ordinary links to the domain. A template saved in your editor is available to its owner for testing, but that does not mean it has been approved or published globally.

## Sharing Instant View links

After a template is available, Telegram can show Instant View for ordinary links to matching articles. To share a direct Instant View link before relying on automatic previews, use the sharing action provided by the Instant View Editor. Telegram generates the required `t.me/iv` URL and template hash; do not construct or guess the `rhash` value manually.

The existing Telegram publisher can continue sending canonical article URLs. Once Telegram recognizes an approved template for the domain, it can render those links as Instant View where supported.

## Template maintenance

The current template follows the repository's Yellow blog layout:

- `system/layouts/blog.html` wraps the post content in `<article>`.
- `system/layouts/blog-start.html` renders the blog index as a list of multiple `<article>` elements.
- The previous and next article links are emitted as paragraphs with `previous` and `next` classes.

If the permalink structure or blog layout changes, update the path condition or XPath selectors and retest the affected articles in the editor.

## Limitations

Instant View is generated by Telegram, not by the website itself. Telegram must be able to fetch each article as public HTML. Private pages, blocked crawlers, unsupported dynamic content, and pages that fail the template's matching rules will open as ordinary web pages instead.
